# Project Brief: stwd.io Frontend

## Project Overview
stwd.io is a global online marketplace that connects musicians, podcasters, bands, and producers with professional recording studios. The frontend is a Next.js application that provides the user interface for both Creators and Studio Owners.

## Core Value Proposition
"Airbnb meets Google Maps for the creative industry" - A centralized, transparent, and streamlined platform that replaces the fragmented process of finding and booking recording studios.

## Primary User Personas

### 🧑‍🎤 Creators (Musicians, Podcasters, Producers)
**Pain Points:**
- Endless Google searches for studios
- Outdated websites and information
- Relying on word-of-mouth
- Sending countless emails for availability and pricing
- No single source of truth

**Solutions Provided:**
- Frictionless discovery and booking experience
- Advanced filtering (location, price, gear, amenities)
- Secure booking platform
- Transparent pricing and availability
- Review system for informed decisions

### 🏢 Studio Owners
**Pain Points:**
- Administrative burden of managing inquiries
- Passive directory listings only
- Email/phone management leading to double-bookings
- Missed opportunities
- Time wasted that could be spent on clients

**Solutions Provided:**
- All-in-one business management tool
- Active revenue-generating engine
- Listing management with rich media
- Calendar and booking management
- Client communication tools
- Analytics and growth insights

### ⚙️ Platform Admins
**Pain Points:**
- Need to ensure marketplace integrity
- Quality control for listings
- Dispute resolution between users
- Platform health monitoring
- Trust and safety enforcement

**Solutions Provided:**
- Admin dashboard for oversight
- Listing verification and approval tools
- Dispute mediation system
- Platform analytics and monitoring
- User management and moderation tools

## Core Requirements

### Authentication & User Management
- Google OAuth integration
- Role-based onboarding (Creator vs Studio Owner)
- Profile management

### Discovery & Search
- Location-based studio search
- Advanced filtering system
- Rich studio profiles with photos and gear lists
- Review and rating system

### Booking System
- Real-time availability checking
- Secure booking flow
- Integrated messaging between users
- Calendar management

### Studio Management (Owner Dashboard)
- Studio listing creation and management
- Booking request handling
- Analytics and insights
- Communication tools

## Success Metrics
- User acquisition and retention
- Booking conversion rates
- Studio owner satisfaction and revenue growth
- Platform engagement and review quality

## Vision Statement
To become the essential operating system for the creative space industry, empowering creativity by removing friction and building connections within a trusted global community.
